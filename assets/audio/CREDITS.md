# Audio credits

Every audio file shipped with the game must be listed here with its license (spec 9.5). The Settings screen reads
the lines that start with "- " and shows them under "Credits and licenses".

Note: at the moment all sound effects are synthesized in code by `AudioService` (no audio files, no third-party
sources), so there is nothing to credit yet. Music loops and stingers are not added yet.

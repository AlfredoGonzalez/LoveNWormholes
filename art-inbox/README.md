# art-inbox

Deja aquí tus imágenes **crudas** (tal como las generó la IA, con fondo magenta o blanco plano), con el nombre EXACTO del archivo final
(por ejemplo `stick_idle.png`, `coin.png`, `bg_egipto.png`). Después ejecuta `npm run art`.
Las imágenes crudas no se suben a git (solo el resultado en `public/assets/`). Lista de nombres: `art-prompts/README.md`.
